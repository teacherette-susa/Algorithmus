# Der Algorithmus entscheidet

Gruppenbildung für Fortbildungen mit eingebautem Automation Bias.

- **Teilnehmende:** Seite auf dem Handy öffnen, Nummer eingeben, Fragen mit Ja/Nein beantworten.
- **Moderation:** `#moderation` an die Adresse anhängen oder unten auf „Moderation“ klicken.

Die Antworten verlassen das Gerät nicht: Es gibt keinen Server. Die Gruppeneinteilung ergibt sich zufällig aus Nummer und Sitzungscode – das wird am Ende aufgelöst.
